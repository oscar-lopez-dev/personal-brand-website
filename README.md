# 🌐 Oscar Lopez — Personal Brand & Portfolio Website

> Modern developer portfolio and personal website built with **Next.js 15 (App Router)**, **React 19**, **TypeScript**, **Tailwind CSS**, and **Vitest**.

[🚀 Live Production Demo](https://personal-brand-website-iota-mauve.vercel.app)

---

## ✨ Features & Architecture

- ⚡ **Next.js 15 App Router** — Optimized server and client component rendering with fast page loads.
- 🎨 **Tailwind CSS Design System** — Fully responsive layout, custom typography, dark-mode ready palette, and modern glassmorphism accents.
- 🧩 **Modular Component Architecture**:
  - `Hero` — Introduction banner and interactive avatar display.
  - `Projects` — Showcase of engineering deliverables with live links and tech badges.
  - `Trajectory` — Chronological timeline of professional experience and achievements.
  - `Pillars` — Core competencies, software engineering principles, and technology radar.
  - `Contact` — Interactive connection and social links section.
- 🌍 **Internationalization (i18n)** — Localized content structure ready for multi-language display.
- 🧪 **Comprehensive Test Coverage** — Unit and component testing powered by **Vitest** and **React Testing Library**.

## 🚀 Getting Started

### Prerequisites
- Node.js 18.x or later
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/oscar-lopez-dev/personal-brand-website.git
cd personal-brand-website

# Install dependencies
npm install
```

### Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the website locally.

### Testing & Verification

```bash
# Run unit tests
npm run test

# Run tests in watch mode
npm run test:watch

# TypeScript type check
npm run typecheck

# Production build
npm run build
```
